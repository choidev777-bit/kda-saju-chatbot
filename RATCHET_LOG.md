# Ratchet Log

This file records repeated failures, unsafe shortcuts, verification gaps, and user corrections that should become durable rules, tests, hooks, CI gates, or tool boundaries.

## Entry Template

### Failure

What happened?

### Evidence

What log, test failure, user correction, or review finding proves it?

### Action

What rule, test, hook, CI gate, or boundary changed?

### Prediction

What should improve next time?

### Review Condition

When will we check whether the action worked?

### Escalation Level

Observation, rule, checklist, test, hook, CI, permission, or tool boundary.
