# Router Checklist

Use this before implementation.

- For a new product or feature idea, start with `office-hours`.
- After office-hours, use `superpowers:brainstorming` to check for missed requirements, unclear scope, and design alternatives.
- After the design is approved, use `superpowers:writing-plans` to create the implementation plan.
- Save the active design link and implementation plan link in `HARNESS_PLAN.md`.
- Start or update workflow state with `node <harness-kit>/src/cli.js workflow start|phase|link-spec|link-plan --target <project>`.
- Is the user asking a general question, brainstorming, implementation, review, or debugging?
- If the request is ambiguous, ask before editing files.
- If the request is risky, identify approval and verification needs first.
- If the request is clear, write completion criteria and a verification plan before changing code.
